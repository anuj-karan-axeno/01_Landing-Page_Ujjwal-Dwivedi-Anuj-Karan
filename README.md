# MyStore

MyStore is a simple storefront website built with plain HTML, CSS, and JavaScript. It shows products from an external API, lets users browse the catalog, and includes a small search experience on the products page.

This project is meant to be easy to read and easy to extend. The layout is mostly static, and the page content is generated by JavaScript when the browser loads the site.

## Project overview

The site has three main pages:

- Home page for the landing section and featured products
- Products page for browsing and searching the catalog
- Contact page for a basic contact form

A shared navbar and footer are reused across pages so the site feels consistent.

## Features

- Responsive storefront layout
- Home page hero section and featured products area
- Products page with live search filtering
- Shared navbar and footer components
- Dark theme toggle with theme preference stored in localStorage
- Product cards with description truncation for cleaner layouts
- External product data loading from the EscuelaJS API

## Setup instructions

1. Open the project folder in VS Code.
2. Start a simple local server if you want to test it in the browser.
   - You can use the Live Server extension in VS Code.
3. Open the home page from the `htmlPages` folder.

If you are opening the HTML files directly from the filesystem, some browser behaviors may be slightly different. A local server is the safer option.

## Lighthouse scores

The project is intended to target these Lighthouse-style goals:

- Performance: 82

These are the target numbers the homepage and page structure are being shaped toward.

## Accessibility considerations

- Semantic headings are used across key sections.
- Images have descriptive alt text where appropriate.
- The dark theme option is added in a way that remains readable.
- The product area and loading/error states are kept understandable for assistive technology.

## Performance optimizations

- Product images use lazy loading where possible.
- Product cards are kept lightweight and simple.
- Only a small number of featured products are loaded on the home page.
- Shared styling is separated into common and page-specific CSS files to keep maintenance simpler.

## Known limitations

- The site is a front-end demo and does not include a full shopping cart or checkout flow.
- Product data depends on a third-party API being reachable from the browser.
- Some pages may still need extra polish if the API returns inconsistent data.
- GitHub Pages deployment details will depend on the final repository settings and branch structure.
